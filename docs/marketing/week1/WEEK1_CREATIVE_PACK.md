# Пак креативов Недели 1 (TikTok + Meta)

Дата подготовки: 2026-03-06
Формат для всех видео: 9:16, 1080x1920, 10-20с, геймплей с первого кадра, вшитые RU-субтитры, без озвучки.

## Подготовка продакшна (один раз)
- Записать 20-30 минут чистого геймплея в OBS.
- Собрать 6 клипов, в каждом 5+ смен сцен.
- Сохранить динамичные SFX/музыку игры; озвучку не использовать.
- Финальная карточка в последние 1.5с: `Играй бесплатно на NebulaClash.com`.

## C1 (c1): "Пройдешь это?"
Целевая длина: 14с

Таймлайн:
- 0.0-1.8с (хук): `Сможешь пройти 1 уровень без бустов?`
- 1.8-7.5с: быстрый чейн комбо + момент на грани поражения
- 7.5-12.5с: камбэк и победа
- 12.5-14.0с (CTA): `Играй бесплатно на NebulaClash.com`

Текстовые вставки (без озвучки):
- `Сможешь пройти первый уровень без бустов?`
- `Я думал, что уже проиграл...`
- `Но вытянул в последний момент.`

Стиль субтитров:
- Хук сверху по центру, action-линии снизу по центру.
